Installation

Composer, for one project or for all of them.

Requirements #

  • PHP 8.5 or later.
  • Composer.
  • Optionally the ds PHP extension, which is used when present. The php-ds/php-ds package comes in as a dependency and does the same job, so it is not needed.

For one project #

This is the recommended way. Barnark is a development tool, so --dev is the right place:

$ composer require --dev rmb32/barnark-cli rmb32/barnark-gui
$ vendor/bin/barnark init
$ vendor/bin/barnark template:list

barnark-cli brings in the library, barnark, and what it needs with it. barnark-gui adds the gui command, and can be left out where only the command line is needed.

For every project #

$ composer global require rmb32/barnark-cli

Then make sure Composer’s global bin folder is on your shell’s PATH. If it isn’t, add this to your ~/.zshrc or ~/.bashrc:

$ export PATH="$HOME/.composer/vendor/bin:$PATH"

Check it:

$ barnark --version

A global install gives you barnark without the vendor/bin/. Everything else in this documentation works the same.

What Barnark adds to your project #

Barnark adds no runtime dependency to your project. It keeps its records in .barn/barnark/, and the folders you clone and add are yours. Where your data lives lists the files.
