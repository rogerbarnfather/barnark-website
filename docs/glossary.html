Glossary

One word, one meaning.

Every term Barnark uses, in alphabetical order. A word means one thing across this whole site, and matches the words in the browser app and on the command line.

Barn
A project with a .barn/ folder at its root, where Barnark keeps its records.
Bound template
The project’s one template that follows its one folder. It is made together with the folder by a clone, and every change to it is a revision. While a template is bound, another clone is refused.
Check
Comparing the bound folder with its template, and reporting what is missing and what is unexpected. Files are never checked.
Clone
To copy a template under a name you give it, as the project’s template, and make its folder. The copy is tied to nothing.
Collection
A folder of a template that holds only members, all of one member type, such as Context in Domain Driven Design.
Copy
To make a new, unbound template of your own from any template, members included, with no folder. Changing one never changes the other.
Dry run
--dry-run on a clone: checks the template, the name and the target, and prints the folders it would make without writing anything.
Fixed folder
A folder the template names itself, such as Kernel or Api. Every folder made to the template has it.
Leaf
A folder of a template with no folders of its own. It is where the template stops and your code begins.
Meaning
The words that say what a folder of a template, or a member type, is for.
Member
A folder you add to a collection and name, such as Reservation in Context. It is part of the template, so adding one makes a revision.
Member type
What a template says once about every member of a collection: what a member is, and which folders it holds.
Missing
A folder the template expects that is not on disk. A kind of inconsistency the check reports.
Revision
One version of a template. Every change adds one, with a reason Barnark writes, and none is changed in place.
Shipped template
One of the five templates Barnark ships: read-only, and changed only by a new Barnark.
Slot
The command line’s word for a member type a folder offers. template:offers lists slots and template:new takes one.
Tag
A label a template gives its folders to say what part each plays, such as Domain. A folder carries the tags of its kind of folder.
Template
A description of what folders a project has and what each is for. Barnark says template for every one, the bound one included.
Unbound template
A template of yours that is not attached to any folder. It can be cloned into a project with nothing bound, or deleted.
Unexpected
A folder on disk that the template does not expect. A kind of inconsistency the check reports.
